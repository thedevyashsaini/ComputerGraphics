Partition-of-unity blending

PER-AXIS WEIGHT OF BRICK i
wi(q) = S( (q − smin) / (cmin − smin) ) · S( (smax − q) / (smax − cmax) )
S(t) = 3t2 − 2t3    (clamped to [0, 1])
BLENDED FIELD
F(x) = Σi wi(x) fi(x) / Σi wi(x)
3D weight = product of the three per-axis weights. s = support edge with ghost cells, c = core edge.
  • S(t) + S(1 − t) = 1, so the two ramps sum to one and centre on the old split
  • S has zero slope at both ends, so F stays C1 across the overlap
  • Faces blend 2 bricks, edges 4, corners 8
  • Outside the overlap F equals the hard-routed model exactly
  • No training, no new parameters
