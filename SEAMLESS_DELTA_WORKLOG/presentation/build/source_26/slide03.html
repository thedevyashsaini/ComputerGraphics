Implicit neural representations

  • A neural network fθ(x, y, z) learns to reproduce the scalar value at any coordinate
  • The weights become the compressed file, so storage depends on model size and not on resolution
  • Random access comes for free: a renderer can query any point without decompressing the volume
  • Training uses random point batches with an L2 loss against the trilinear ground truth
