Domain decomposition and ghost cells

  • Large volumes do not fit one model or one GPU, so the paper splits the domain into n × n × n bricks
  • One independent APMGSRN per brick, trained in parallel
  • Ghost cells extend each brick into its neighbours so both models see the shared boundary
  • Hard router: brick index = floor((x + 1) / 2 × n)
